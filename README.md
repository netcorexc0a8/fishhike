# FishHike — спутник рыбака и туриста

PWA для рыбалки и походов: прогноз клёва по погоде и Луне, списки сборов, походные рецепты и сохранённые места. Работает офлайн и устанавливается на телефон как приложение.

## Возможности

- **Прогноз клёва** — почасовой индекс 0–10 на 16 дней для выбранного места (дни дальше 7-го помечены «ориентировочно»). Учитывает солунарные периоды (точные кульминации, восход и заход Луны для координат места — `astronomy-engine`, офлайн), утреннюю и вечернюю зорьку, тренд давления, ветер, осадки и фазу Луны. Погода — [Open-Meteo](https://open-meteo.com) (без ключа). Последний прогноз кэшируется и показывается без сети.
- **Улов** — журнал пойманной рыбы: вид, вес, длина, дата, место (с координатами по GPS), снасти и заметка. Фото с камеры или из галереи сжимается на телефоне до 1280px (WebP/JPEG) и хранится в IndexedDB. Без своего фото показывается снимок вида. Сводка, группировка по месяцам, фильтр по виду; последний улов — на экране прогноза.
- **Сборы** — чек-листы с прогрессом: создание, копирование из шаблона, отметки, переименование, удаление. Два стартовых шаблона.
- **Рецепты** — базовые походные рецепты и свои: поиск, создание, редактирование, удаление. Клиентская проверка стоп-слов.
- **Карта** — сохранённые места, улов с координатами и треки на подложке OpenStreetMap (открывается из России, без ключа). Просмотренные плитки кэшируются и видны без сети. Из записи улова — «Показать на карте».
- **Запись трека** — маршрут по GPS с паузой: расстояние, время в пути, точность. Запись продолжается при переходе между вкладками. Экран не гаснет на время записи (Screen Wake Lock, где поддерживается). Ограничение браузера: в фоне и при погасшем экране телефон не отдаёт координаты, поэтому перерыв дольше двух минут начинает новый отрезок, без прямой через весь перерыв. Шумные точки (точность хуже 50 м, скачки быстрее 25 м/с) отбрасываются.
- **Места и настройки** — с карты: текущая геопозиция или поиск водоёма по названию, тема, резервная копия.
- **Офлайн** — все данные в IndexedDB, оболочка приложения кэшируется service worker'ом.
- **Резервная копия** — «Карта → Места и настройки → Резервная копия»: все сборы, рецепты, журнал улова (с фото), треки, места и тема в одном JSON-файле. На телефоне файл отдаётся через системное «Поделиться» (AirDrop, Telegram, «Файлы»), на другом устройстве — «Восстановить». Данные объединяются по id (побеждает более свежая правка), ничего не удаляется.

## Стек

Vite · React 19 · TypeScript · React Router (HashRouter) · Dexie (IndexedDB) · Leaflet · vite-plugin-pwa (Workbox) · Vitest. Шрифт Golos Text встроен в сборку и работает без сети.

## Разработка

```bash
npm install
npm run dev        # http://localhost:5173
npm test           # юнит-тесты (луна, индекс клёва, кэш, модерация)
npm run build      # сборка в dist/
npm run preview    # проверить собранную версию, включая service worker
```

## Деплой

Workflow `.github/workflows/pwa.yml` на каждый PR прогоняет проверку типов, тесты и сборку, а при пуше в `main` публикует приложение на GitHub Pages.

Адрес приложения: **https://fishhike.wg3664.ru**. Сборка рассчитана на корень домена. Для публикации в подкаталоге (`<user>.github.io/fishhike/`) задайте переменную репозитория `BASE_PATH=/fishhike/` (Settings → Secrets and variables → Actions → Variables).

Настройка домена (один раз):
1. DNS: `fishhike.wg3664.ru CNAME netcorexc0a8.github.io` (в Cloudflare — режим «DNS only»).
2. Settings → Pages → Custom domain: `fishhike.wg3664.ru`, затем включить **Enforce HTTPS**.

## Доступ к погоде из России

Основной адрес Open-Meteo из части российских сетей недоступен. Приложение перебирает адреса по очереди и запоминает рабочий на 30 дней (`src/lib/hosts.ts`):

- прогноз: `api.open-meteo.com` → `historical-forecast-api.open-meteo.com` (тот же `/v1/forecast`);
- поиск мест: `geocoding-api.open-meteo.com`.

Каждой попытке даётся 7 секунд.

Подложку карты можно заменить переменными `VITE_TILE_URL` (шаблон `https://…/{z}/{x}/{y}.png`) и `VITE_TILE_ATTRIBUTION` (`src/lib/tiles.ts`). Списки можно переопределить переменными репозитория `VITE_FORECAST_HOSTS` / `VITE_GEOCODER_HOSTS` (адреса через запятую) — например, если позже появится свой прокси.

## Структура

```
src/
  lib/          чистая логика: moon.ts, bite.ts, weather.ts, geo.ts, recorder.ts, format.ts, moderation.ts (+ тесты)
  screens/      экраны: прогноз, улов, сборы, рецепты, карта, места и настройки
  components/   TabBar, Moon, BiteBars, Icon
  db.ts         схема IndexedDB, seed.ts — стартовые данные
  hooks.ts      текущее место, геолокация, загрузка и кэш прогноза
legacy/flutter/ прежняя версия на Flutter (для справки)
```
